# 🛒 CheckIt

**CheckIt** is an intuitive application designed to manage your shopping lists efficiently, ensuring you never forget an essential item again. Organise your products by category or supermarket and maintain complete control over your errands. 
### ✨ Key Features
- Personalised Organisation: Create specific categories or supermarket names to group your products.
- Smart Sorting: Assign products to categories on the fly.
- Default Management: In a hurry? Unassigned products are automatically moved to the ‘Uncategorized’ section.
- Clean Interface: Designed to make adding products quick and easy.

### 🛠️ Technology Stack

**React + Vite:** Main library and high-speed build environment.

**TypeScript:** Static typing to ensure robust, error-free code.

**CSS modules:** Utility-based styling for a modern, minimalist design.

**Supabase:** Database creation and management, REST API consumption, authentication management with Supabase Auth.
